## 6. 接续时必须保留的宿主事实

`logger` 是上下文属性，不能作为必需注入服务。搜索子入口 inject 仅为 credentials，其余通过动态注入获取。主入口默认导出必须包含 Config；volatile 搜索设置归入 `icarus` 命名空间，搜索子入口的空 Config 不产生独立设置表单。

宿主 connection.rpc getter 捕获的 Cordis 上下文不能直接注册所需路由。`src/search/host-rpc.ts` 复用 connection 的同一认证和状态引用，将 ctx 绑定到已注入 webServer 的搜索插件上下文；路由生命周期也归属该插件。该实现已通过真实启动、认证 RPC 与 web 重载验证。

搜索插件的动态注入分两层：设置面只依赖 `connection` 与 `webServer`，接管面依赖 `web` 与 `configEditor`。宿主服务缺失时 `ctx.inject` 的回调不会执行，宿主自己的启动诊断也只列 Loader 条目声明的 inject，因此缺失的服务名由 `searchStatus` 用 `ctx.get(name)` 在调用时确定并回报；已核查 `web` 缺失会让宿主自身的 `tool-web` 启动失败，`config-editor` 缺失时宿主可正常运行。

SettingsFormModel 与 SettingsSecretField 由宿主提供。密钥输入走 `remote.credentials.set`，不回读原值。MarkdownText 的内容属性名为 text；教程按段分别渲染，英文金额写 USD，避免宿主数学公式解析干扰显示。

当前 schema 为 9。SearchCall 在执行前事务预留，取消或未知结果保留额度预留。成功响应的计量优先读取厂商字段。凭据内容只在内存中比较，状态持久化不保存 key。
