## 功能4：长短时记忆动态补充

**论文摘要：** 选用 **AgeMem** 框架（2026年ArXiv）研究LLM智能体的统一记忆管理。**问题**：解决LLM智能体有限上下文窗口下的长期推理瓶颈；**方法**：提出 Agentic Memory (AgeMem)，将长期记忆（LTM）和短期记忆（STM）作为工具操作集成进智能体策略，让智能体自主决定何时存/取/更新/摘要/丢弃信息。采用三阶段渐进RL策略和分步GRPO算法应对记忆操作产生的稀疏奖励。**结果**：在五个长时推理基准上，AgeMem明显优于基线，提升任务成功率、更高质量的长期记忆与更高效的上下文使用；**局限**：当前工具集固定、评估环境受控，对更开放场景需进一步研究。

**插件评估：** 深度记忆系统的插件可选 **MemOS Memory OS**（Simon Sax, ★11893）。MemOS提供持久化跨会话记忆、混合检索和跨任务技能复用，可极大增强Agent记忆。功能：自动将重要信息保存在知识库，下次对话中优先检索，声称节省35%上下文token。与AgeMem相比：插件侧重记忆的存储与检索，缺少主动记忆操作策略（无RL管理），但即插即用易部署；可作为工具补充Agent记忆层。**替代方案**：LangChain的LangMem SDK（LangChain团队2025）或自建向量数据库。

## 功能11：Agent自身进化（无模型微调）

**论文摘要：** 参考《Reflect, Retry, Reward: Self-Improving LLMs via Reinforcement Learning》。该论文提出LLM通过“反思-重试-奖励”迭代框架自我提升。**问题**：如何在保持模型参数不变的前提下，通过内部机制让模型变得更好；**方法**：当模型回答失败时，生成自我反思文本分析错误，并在反思上下文中重新尝试完成任务；若重试成功，则给予反思阶段的输出回报，强化其质量。无需额外数据，适用于只有二值反馈的场景。**结果**：在数学题、函数调用等任务上，模型表现显著提升（高达34.7%和18.1%）；小模型（1.5B-7B）在改进后甚至超越了未经调整的大模型。**局限**：实验在可评估任务上执行（需要验证成功与否），对开放域问题的成效未知；依赖有效的失败检测和反思提示。

**插件评估：** 可借用 **weibaohui/hermes-loop** 自动复盘插件，其会在对话结束后蒸馏有价值的经验为技能并存入知识库，类比反思并总结的过程。另**ZK-Andy/dsh-continual-evolve**（持续自进化插件）可将对话轨迹版本化、可审计、可回滚，并支持技能热加载，符合保持权重不变的自进化思路。替代方案：**btspoony/dsh-propose**等回环插件可自我调整任务策略。总之，这些工具强调基于会话轨迹和反馈迭代改进，而非调参，符合需求。
